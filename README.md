# NexClinic

NexClinic is an AI based healthcare management system developed by the Nexaura team. The platform is designed to connect patients and doctors through a single digital solution.

The system allows users to register and log in securely manage doctor appointments handle patient doctor interactions and receive medication and health related reminders. It is built with scalability in mind and prepared for future AI powered healthcare assistance.

## Features

- Patient and doctor registration and login
- Role based dashboards
- Appointment and channeling management
- Medication reminders
- Secure data handling
- AI ready system architecture

## Project Goal

The goal of NexClinic is to simplify healthcare interactions by improving accessibility efficiency and overall user experience for both patients and doctors.

## Technologies Used

- Backend Django
- Frontend Web based interface
- Database Relational database system
- AI Planned integration for healthcare support
